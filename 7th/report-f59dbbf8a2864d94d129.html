유버디가 드리는 말

Selina 님의 고민은 영어로 발표하는 것이고, 게다가 듣는 분들이 모두 서양인 의사들이라 조금 떨리는 것도 있으실 것 같아요. 근데 저는 오히려 기술직이라 다행이다 싶은 생각도 들었어요. 데이터로 설명하는 거고, 결과 보고를 이미 잘 하고 계시거든요.

여기서 가장 중요한 건 계속 말해보는 자세예요. 저라면 의학 용어 팟캐스트랑 관련 자료를 더 많이 찾아서, 적어도 리스닝에서는 막히지 않게 만들어둘 것 같아요.

그리고 말씀하실 때 표정을 정말 잘 쓰세요. 그래서 대화할 때도 잘 통하실 거예요. 여기에 맞장구 치는 문장, 그리고 냉철하게 "그건 아닌 것 같다"고 할 때 쓰는 문장을 각각 10개씩 늘려서 골라 쓰시는 걸 추천드려요 ㅎㅎ

오늘 가장 좋았던 것

배운 표현이 사흘 만에 본인 문장이 됐어요
"With a caveat, some important variables are still missing."
"The main workflow is still underway."
연습 문장이 아니라 진짜 주간 보고 안에서 나왔어요. 그리고 전부 숫자로 말하신 것도 좋았습니다. 30%, 두 개의 training, second revision. 외국계 회의에서 신뢰를 만드는 건 유창함이 아니라 이 구체성이에요.

⭐ 이번에 가져갈 표현 3개

1Take it offline
이 얘기는 회의 끝나고 따로 하죠
"Let's take it offline and I'll follow up after the meeting."
2We don't have the bandwidth
지금 그걸 할 여력이 없어요
"We don't have the bandwidth before the report deadline."
3This is a blocker
이것 때문에 다음 단계가 멈춰 있어요
"The pending data approval is a blocker for the cohort build."

프레젠테이션 피드백

Q. 제가 물어봤죠
"If the Vital and ADI variables don't come through in time, would you proceed with imputation?"
Vital 은 키·몸무게·BMI 라 다른 데이터로 대체가 안 되고, ADI 는 소득 관련이라 건너뛸 수 있다고 나눠서 답하셨어요.
이 답이 오늘 제일 좋았어요. "둘 다 필요해요"가 아니라 왜 하나는 되고 하나는 안 되는지를 갈라서 말하셨거든요. 다음엔 앞에 한 문장만 붙여보세요. "Let me break that down." 듣는 사람이 준비하고 들어요.
Q. 제가 물어봤죠
"Is AI helpful for that part of your work?"
환자 데이터라 ChatGPT 를 쓸 수 없고 코딩을 직접 하신다고요. 그리고 Jack 이 카드를 꽂아줘야 분석을 시작할 수 있다고요.
카드 꽂아줄 사람 기다렸다가 분석 시작하는 거, 그거 진짜 답답하시겠어요. 그 상황을 말할 때 쓰는 표현이 있어요. "He badges me in so I can run the analysis." badge in 이 카드로 출입 인증하는 그 동작이에요.
Q. 제가 물어봤죠
"What is the hardest part, aside from the English?"
"I should know both computer science and medical terms. I think I'm in the middle."
"I'm in the middle" 을 약점처럼 말씀하셨는데, 영어권에서는 그게 강점으로 팔리는 자리예요. 둘 다 아는 사람이 드무니까요. 단어 하나만 바꾸면 됩니다. "My work is highly interdisciplinary."

이렇게 말하면 더 자연스러워요

빈칸을 먼저 채워보시고, 아래 정답을 열어보세요.
회의가 딴 길로 샐 때 · 이 얘긴 끝나고 따로 하자
"... and then table it offline."
Let's ____ __ ________.
정답 보기
Let's take it offline.
Table it 은 안건을 나중으로 미루기, Take it offline 은 이 얘기를 회의 끝나고 따로 하기. 두 개가 붙어버렸어요. 그날 상황은 take it offline 쪽이었어요.
지금 그걸 할 여력이 없다고 할 때
"'Cause we don't have any cycle."
We don't have the _________.
정답 보기
We don't have the bandwidth.
cycle 은 "무슨 주기?"로 들려요. 회의에서 두 번 쓰셨는데 둘 다 bandwidth 자리였어요.
⚠️ 환자 데이터 보안을 설명할 때 · 뜻이 반대로 나갔어요
"Patient data is so private, so we can use internet and any ChatGPT."
Patient data is sensitive, so we ____ use ChatGPT for it.
정답 보기
... so we can't use ChatGPT for it.
not 이 빠지면서 "환자 데이터에 ChatGPT 를 씁니다"로 들렸어요. 보안 얘기라 오해가 크게 날 수 있는 자리예요. 뒤에 "That's restricted for HIPAA reasons." 를 붙이면 더 안전해요.
Jack 이 카드를 꽂아줘야 분석이 시작될 때
"He should insert his card to my laptop ... we are pair."
He ______ me in, and we're _______ up for data access.
정답 보기
He badges me in, and we're pairing up for data access.
pair 는 명사라 그대로 못 써요. 카드로 인증하는 건 badge in 이 딱이에요.
발음 · 매주 나오는 두 단어예요
"first one is a general revision" / "health tech up data"
_______ revision / health _______ data
정답 보기
journal revision / health checkup data
journal 은 [저-널] 두 음절로 끊고, checkup 은 [체컵]에 가깝게. 이 둘만 잡아도 전달력이 확 올라가요. 나머지 문법(both of thing, a AI model)은 이미 아시는 규칙이라 발표 직전에 소리 내어 한 번 읽으면 안 나와요.

연구 직무에서 알아두면 좋은 표현

ETL (Extract, Transform, Load)
흩어진 병원 데이터를 끌어와 정리하고 합치는 과정 전체. "merge split data" 대신 "the ETL pipeline for the hospital records"
Feature selection
ADI, Vital 중 어떤 변수를 쓸지 고르는 작업. "We're still doing feature selection."
PII · HIPAA compliance
환자 데이터 접근 권한 얘기가 나올 때. 규정을 지키고 있다는 신호를 같이 줘요. "Access is restricted for HIPAA compliance."
Interdisciplinary
CS 와 의학을 동시에 다뤄야 하는 본인 일의 성격. 자기소개에서 강점으로 쓰기 좋아요.

외국계에서 더 잘 통하는 방식, 알고 계셨나요?

숫자 뒤에 성공 기준 붙이기
Selina 님 이미 숫자로 정말 잘 말하고 계세요. 여기에 "목표는 이번 달 말 70%" 처럼 기준을 붙이면 듣는 사람이 판단할 수 있게 돼요.
기다린다고만 하지 않기
"waiting for approval" 로 끝나면 그냥 근황이에요. 그 대기가 뭘 막고 있는지까지 말해야 우선순위가 올라가요. "This is blocking the cohort build."
모르는 약어는 그 자리에서 되묻기
의학 약어가 빠르게 지나갈 때 "Sorry, what does that stand for?" 한 문장이면 돼요. 되묻는 건 실력 부족이 아니라 정확성을 챙기는 사람의 태도로 읽혀요.
