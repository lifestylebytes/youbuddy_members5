## 1. AI 첨삭 신뢰성 (5기부터 누적, 7기에서 3층 방어 완성)

**터졌던 것**
- 동의어 스왑 핑퐁: increase→raise→increase... 재첨삭마다 다른 답 → "뭐가 맞는 거야?" 신뢰 붕괴
- 학습 단어를 유의어로 갈아치우거나 통째로 삭제
- 단복수/관사 동시교정을 스왑으로 오인해 진짜 교정을 폐기
- 스왑 차단을 세게 걸었더니 반대로 과관대: 진짜 오류(오철자·콜로케이션)까지 "이미 자연스러워요" 통과
- 고쳐준 문장을 붙여넣어 재제출하면 또 다른 교정 (프리미엄 무제한 재첨삭에서 치명적)

**현재 가드 (7기)**
1. 클라이언트 에코 가드: 이전 AI corrected 와 동일 재제출 → AI 호출 없이 "최종 확정 ✓". 히스토리는 state.ai_history 로 영속화 (새로고침·재로그인 무관)
2. 서버 에코 가드 + seed 고정 (동일 입력 → 동일 출력)
3. 프롬프트: verdict(correct|fixed) 판정 + "진짜 오류는 1단어여도 반드시 교정" 예외 + ECHO RULE(자기 교정본 재수정 금지). 클라이언트 휴리스틱은 서버 fixed 판정 시 양보
- 학습 단어 보존: 서버 슬롯 검증 + 재시도 + 클라이언트 fallback (기존 유지)

**운영 루틴**: 첨삭 로직 만지면 `_archive/스킬/qa-scripts/sim_ai_review.js` 실행. edge function 수정 시 `supabase functions deploy ai-review --no-verify-jwt` 재배포 필수.

## 2. 단어시험 정답 노출 (6기 Day16~20, 7기 4건)

**터졌던 것**: 예문 속 표현이 변형(과거형 greenlit, 관사 삽입 put out *some* feelers)이면 빈칸 매칭이 실패해 문장이 통째로 노출 = 답이 그대로 보임. 멤버가 발견해서 제보함 (창피 포인트).

**현재 가드**: 빈칸 로직이 시제 변형 + 관사·수량사 삽입/교체까지 매칭 (computeQuizSplit 2.5단계). 6th/7th 동일 적용.

**운영 루틴**: 단어·예문 하나라도 바꾸면 `sim_quiz7.js` 전수 시뮬레이션 → leak 0 확인 후 커밋. 신규 기수 단어 주입 시 필수.

## 3. 팝업/모달 사고 (6기 최다 발생 카테고리)

**터졌던 것**
- 주간 회고 설문 무한 반복 노출 ("나 이거 왜 자꾸 뜨는 거임??")
- 미팅 동의 팝업 무한 루프 + 두 번 플래시
- 자동 팝업들이 다른 모달 위에 겹침
- 사전설문 백드롭이 안 지워져 스크롤 먹통
- 데일리 팝업 싱글턴이라 Day 넘겨도 안 갈림

**현재 가드**: anyPopupOpen() 체인 (새 팝업 만들면 반드시 여기 등록), 노출 플래그는 반드시 persist (세션 변수만 쓰면 재접속마다 또 뜸), 팝업마다 독립 렌더 블록 + data-attr 로 stale DOM 제거.

**새 팝업 체크리스트**: ① anyPopupOpen 에 플래그 추가했나 ② seen 플래그 PERSISTED_STATE_KEYS 에 넣었나 ③ 렌더 블록에 else-remove 있나 ④ 닫기 경로 전부(X·백드롭·버튼)에서 플래그 세팅하나.

## 4. 상태·캐시 오염

**터졌던 것**
- 7th 가 6th 와 localStorage 키(yb5_*)를 공유해 6기 캐시를 읽고 덮어씀 → 온보딩 안 뜸, 상태 오염 (크리티컬)
- 서버에서 리셋한 상태가 로컬 stale 캐시로 부활
- 배포 직후 구버전 캐시 (하드 리프레시 필요)

**현재 가드**: 기수별 LS 키 분리 (yb7_state_cache_v1 등). **8기 만들 때 1순위 작업 = yb8_* 로 리네임.** 업데이트 배너는 ETag 정규화 + 20초 재확인 + 태그 기억으로 오탐 제거됨.

## 5. 시차·마감 판정 (해외 멤버)

**터졌던 것**
- lookupCode 가 tz 를 안 실어 코드 로그인 시 +0h 로 떨어짐 (해외 멤버 마감 미적용)
- 운영자 지정 tz 가 서버 저장값에 밀림
- currentDay 가 디바이스마다 다르게 잡힘

**현재 가드**: 디렉토리 tz > 서버값 > 본인 입력 우선순위 고정. 콘텐츠 공개는 KST, 마감 판정은 본인 시차. 7기는 운영자 지정 없이 온보딩 자동감지+본인 입력 (Selina·서보경). 
**운영 루틴**: 해외 멤버는 Week 1 중 프로필에서 시차 표기 맞는지 한 번 확인.
