# 유비챌 8기 백로그

7기 운영하며 쌓이는 8기 개선 후보. 결정 전 아이디어 보관소.

## 1. 발음 코칭 (녹음 → 받아적기 → 피드백)

6기 회고 "카톡 음성 인증에 피드백 주기 애매함"의 정면 해결책. 기술적으로 가능함.

**구현 방식 (난이도 순)**
1. **Web Speech API (무료, 브라우저 내장)**: 마이크로 말하면 실시간 받아적기. 서버 불필요.
   한계: 크롬 위주(iOS 사파리 제한), 발음 점수는 없고 "인식됐는지"만 확인 가능.
   용도: "오늘 문장 소리내어 읽기 → 인식되면 통과" 게임화. 비용 0원.
2. **Whisper API + GPT 피드백**: 녹음 파일을 서버(edge function)로 보내 받아적고,
   원문과 비교해 "어디가 안 들렸는지" 텍스트 피드백. 분당 약 8원. 기존 ai-review
   프록시 패턴 그대로 확장 가능 (mode: 'pronounce').
   한계: 음소 단위 발음 점수는 없음 (억양·강세 코칭 불가).
3. **Azure Speech Pronunciation Assessment**: 스픽·BoldVoice 급. 음소/단어/문장별
   정확도·유창성·완성도 점수 + 어떤 소리가 틀렸는지 리턴. 시간당 약 1,300원 수준.
   구현: 브라우저 MediaRecorder → edge function → Azure REST. 오늘 문장을 참조
   텍스트로 주면 문장 맞춤 채점이 됨 (유비챌 구조와 찰떡).

**추천 로드맵**: 8기 베타 = 2번 (Whisper, 구현 1~2일 감). 반응 좋으면 프리미엄
전용으로 3번 (Azure 점수화) 업그레이드. 1번은 데일리 인증 게임화로 병행 가능.

## 2. 위클리 리뷰 공개 (6기 회고 아이디어)

위클리 설문 답변이 유버디에게만 보여서 아까움 → 커뮤니티에 "이번 주 목소리" 블록으로
익명/실명 선택 공개. 콘텐츠 관리 부담이 걱정이면: 운영자가 승인한 답변만 노출하는
큐레이션 방식 (승인 버튼만 추가하면 됨).

## 3. 인더스트리 맞춤 (도현님 피드백)

사전설문의 업계/직무 답변을 AI 첨삭 프롬프트에 넣어 예문·피드백을 본인 업계 맥락으로.
(관광업이면 호텔·투어 시나리오 예문) 데이터는 이미 받고 있음, 프롬프트 연결만 하면 됨.

## 4. 기타 후보

- 프리미엄 발표 후 개별 피드백 정례화 (6기 회고 후보 항목, 7기에서 운영해보고 결정)
- 상세페이지 카피: "비즈니스 영어에도 단계가 있다, B2에서 C1으로" (주혜님 인터뷰 기반,
  youbuddy-detail-page 저장소 작업)
- 프리미엄 차별점 카피: "비즈니스 어휘 구독 + 환경 구매 + 회사에서는 받을 수 없는 피드백"

## 구매 전 고지 (8기 필수)

- 결제/신청 페이지에 **후기·설문 활용 고지** 추가: 주간 설문·후기로 남겨주신 내용은
  유버디 인스타 스토리·게시글·상세페이지에 활용될 수 있음을 구매 전에 안내.
- 권장 문구 (신청 폼 동의 항목):
  "챌린지 중 남겨주시는 주간 설문·후기는 유버디 콘텐츠(스토리·게시글·상세페이지)에
  소개될 수 있어요. 이름은 닉네임/이니셜로만 표기됩니다. 원치 않으시면 설문에서
  '비공개 희망'을 선택하시면 절대 사용하지 않아요."
- 세트로: 주간 설문 마지막에 "이 답변, 유버디 게시글에 소개돼도 괜찮나요? (좋아요/비공개 희망)"
  선택지 추가 → 멤버별 명시 동의가 남아 안전 + 비공개 선택자 자동 제외 가능.
