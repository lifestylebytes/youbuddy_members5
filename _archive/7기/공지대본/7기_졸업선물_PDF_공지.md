## 공지 1 · 단톡방 메인 (베이직 + 프리미엄 공통)

```
해피 day17입니다 :)

이제 진짜 며칠 안 남았어요.
오늘은 마지막 날에 드릴 선물 하나 미리 말씀드리려구요~

바로.. <4주 단어집 PDF> 입니다!

Day 1부터 20까지 배운 단어 60개를
- 발음기호랑 품사
- 실제 회사에서 쓰는 예문 (영어 + 한국어)
- "이럴 때 써요" 뉘앙스 설명
- 같이 알아두면 좋은 유의어 120개

이렇게 한 권으로 묶었어요.
26페이지짜리라 폰에 넣어두고 회의 들어가기 전에
한 장씩 펼쳐보시면 딱이에요 :)

받으시는 조건은 두 가지예요.

1) 인증 18점 이상
2) 파이널 테스트 완료

인증 점수는 정시 인증 1점, 지각 인증 0.5점이에요.
자정 지나도 인증은 계속 열려 있으니까
놓친 날 있으면 지금이라도 들어가서 채우시면 돼요~!

파이널 테스트는 점수 기준이 따로 없어요.
제출만 하시면 완료로 처리됩니다 :)

앱 들어가시면 팝업으로
"지금 내 점수가 몇 점인지, 몇 점 더 채우면 되는지"
정확하게 보여드리고 있어요. 한 번 확인해보세요!

혹시 계산해봤는데 좀 애매하다 싶으시면
부담 없이 저한테 톡 주세요 🧡
```

