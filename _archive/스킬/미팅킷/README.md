새 기수 단어가 확정된 뒤 이 문서 하나로 미팅 준비가 끝나야 한다. 마지막 갱신: 2026-07-15.

## 8기 전환 순서 (Week 1 기준, 총 ~30분)

1. 새 기수 단어 주입 완료 후 `grep -n "COHORT-SLOT" 7th/index.html`
2. WEEK1_SIM 재작성: 아래 "시뮬 생성 프롬프트"를 Claude 에게 그대로 요청
3. 로드맵/예고 슬라이드 문구: 새 기수 주차 테마로 교체
4. 대본: Week1_대본_템플릿.md 슬롯 채우기 (Claude 에게 "템플릿 + 새 단어 12개 + 진단지 요약"으로 요청)
5. 진단지 CSV 받으면 코칭 시트 재생성 (파일명 *_비공개.md 필수, gitignore)
6. 검증 3종: vm 파스 + em dash 0 + audit 스크립트. "가비" grep 0 도 확인
7. 운영 스위치 확인: __PT_HIDDEN, PRESENTER_CAP_OVERRIDE, __MEETING_OPEN_MAX_WEEK

## 시뮬 생성 프롬프트 (Claude 에게 그대로)

> Day 1~4 단어 12개(en/def/ex_en)를 줄게. 각 단어마다 "회의 시뮬" 1문항을 만들어줘.
> 형식: { ko: '상황 한 줄(한국어, 리얼한 회사 장면)', cue: '상대방이 나에게 하는 말(영어 한 문장, 답을 짐작하기 쉽게)', pre: '내 대답 앞부분', ans: '타겟 표현(자연스러운 굴절형 허용)', post: '내 대답 뒷부분' }
> 규칙: ① pre+ans+post 가 실제 회의에서 할 법한 완성 대답일 것 ② ans 는 첫 글자 힌트로 보임 ③ 12개가 다양한 직군(영업/재무/HR/개발/PM) 상황을 커버 ④ WEEK1_WARMUP 과 같은 단어 순서 (패스 인덱스 호환) ⑤ em dash 금지.
> 완성되면 7th/index.html 의 WEEK1_SIM 을 교체하고 vm 파스 검증까지.

## Week 1 미팅 뼈대 (검증된 v8 구조, W2~4 도 이 틀 위에)

① Who you are (자기소개+영어 장면) → ② What you want to build (4주 목표, 첫 주만)
→ ③ What you brought (내 문장 라운드: 상황 설명+낭독+토스) → ④ What we practice together
(공통 표현을 회의 반사신경으로: 시뮬) → ⑤ What you'll try next (새 목표 X, 다음 주 사용 장면 1개)

불변 원칙 (CLAUDE.md 미팅 대본 원칙과 동일): 버디=환경 제공자, 미니 강의 없음, 안전선언,
one-scene 마무리, **성장 증거 짚기** ("아까 안 나오던 게 지금 나왔죠"), 진단지/앱 데이터 호명.

### W2~4 변형 포인트 (개정 시 이 틀에 얹기)
- W2~4는 ②(4주 목표) 대신 "지난주 사용 장면 후기 라운드" (복습 시트의 장면을 실제로 썼는지 1분씩) ← 연속성+책임감
- ③ 문장 라운드는 동일 (pre_submit 인프라 그대로, __MEETING_OPEN_MAX_WEEK 만 올리면 페이지 열림)
- ④ 시뮬은 그 주 단어로 재작성 (WEEK2_SIM... 같은 패턴, 렌더러는 meetingSim 재사용: __curDeck 처럼 주차별 데이터만 분기)
- PT 발표 있는 주는 ④ 앞에 발표(7+3분) 삽입, 시뮬 문항 12→8개로 축소
- 마지막 미팅(W4)은 ⑤ 대신 "내 업무 영어 대본 완성 + 재등록 오퍼" (아래 수료 리포트와 연결)

## 프리미엄 수료 리포트 ("내 업무 영어 대본") 설계 초안

멤버별로 4주간 쌓인 데이터를 묶어 수료 시 발행하는 개인 리포트. 재등록의 핵심 증거물.

**데이터 소스 (전부 이미 서버에 있음, get_cohort_meeting_notes m1~m4 로 추출):**
- timeline.week_note.cohort_goal (4주 목표) · week_goal (주차별 사용 장면)
- timeline.pre_submit (주차별 내 문장 = before) · week_note.new_expressions (미팅에서 얻은 것 = after)
- week_note.missed_words (약점 이력 → "이만큼 잡았다" 서사)
- + 앱 학습 데이터: AI 첨삭 히스토리 (문장 성장 before/after), 인증/퀴즈 성적

**리포트 구성 (1인 1장):** 표지(이름+기수 목표) → 주차별 "내 문장" 타임라인 (원문 → 다듬어진 문장)
→ 내가 가져간 표현 모음 → 4주 성장 요약 (숫자: 문장 N개, 표현 N개, 인증 N일) → 다음 기수 처방 1줄.
**발행 방법:** 수료식 카드뉴스 스킬(youbuddy-graduation-cards)에 "프리미엄 개인 리포트" 모듈로 추가
또는 별도 PDF 생성. 멤버 이름 포함이므로 커밋 금지 (.gitignore 확인).
