# QA 스크립트 (기수 공통 재사용)

새 기수 페이지를 만들거나 단어 데이터를 바꿀 때마다 돌리는 자동 검사 3종.
경로만 새 기수 폴더로 바꿔서 실행 (`node <스크립트>`).

| 스크립트 | 검사 내용 | 언제 |
|---|---|---|
| `sim_quiz7.js` | 단어시험 정답 노출 전수 검사 (60단어 x 빈칸 로직 시뮬레이션, fallback/잔여노출 감지) | 단어·예문 수정할 때마다 |
| `audit7b.js` | 데이터 정합성 (단어 수·중복·빈 필드, 유의어 사전 커버리지, 약점단어·빙고 참조, 날짜·요일, 미팅 요일) | 런칭 전 + 데이터 수정 시 |
| `sim_ai_review.js` | AI 첨삭 에코 가드·히스토리 영속화 단위 테스트 | 첨삭 로직 수정 시 |

공통 필수 검사 (스크립트 밖):
- `node` vm 파스 체크 (최대 script 블록 추출 후 `new vm.Script()`)
- `grep -c "—"` = 0 (em dash 전역 금지)
- 이전 기수 흔적 grep: 이전 기수명, 구 드라이브 링크, 구 latpeed 링크
