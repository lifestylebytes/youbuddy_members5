# 다큐라이즈(DocuRise) 건의·문의 모음

11기 퍼널을 다큐라이즈로 옮기면서 막힌 것들. 고객센터에 한 번에 보낼 용도. (2026-11-06 시작, 2026-11-08 카테고리별로 재정리)

## 1. 결제·판매
1. **판매 웹훅 / 주문 CSV 내보내기 없음**: 결제 완료 시 외부로 웹훅을 쏘거나 주문 목록을 CSV로 받을 방법이 없음. Google Sheets 연동은 Iconic 전용이고 "리드" 동기화라 구매자 시트(이름·이메일·상품·금액·결제일)를 따로 쌓기 어려움. 최소한 주문 CSV 다운로드 + 결제 완료 웹훅 요청.
   - 화면: https://docurise.io/dashboard/documents/dceaadb2-452b-49be-9597-7a2fe6a27250 (11기 결제 폼)
2. **결제 완료자가 "제출 후 화면" 포스트에 다시 못 들어감**: 제출자만 열 수 있어서, 결제한 사람이 나중에 다시 못 들어옴. 결제 완료자는 재방문 허용되게.
   - 화면: https://docurise.io/dashboard/documents/46ad1bd0-cb8e-4a0f-bd36-36a215fc2802 (결제 완료 안내 포스트)
3. **해외 발급 카드 결제 가능한가요?**
   - 화면: https://docurise.io/v/youbuddy-challenge-11

## 2. 이메일·알림톡 자동화
4. **수신자 0명이면 예약 발송을 못 거는 문제** (꼭): 그룹(예: "최근 1일 결제 이탈") 대상 예약을 걸어두고, 발송 시각에 그룹을 다시 세서 0명이면 건너뛰고 N명이면 보내게 "켜둘 수" 있게. 지금은 누르는 순간 0명이면 버튼이 비활성화라 결제 이탈 메일을 매일 손으로 보내야 함.
   - 같이 궁금한 것: **예약한 메일은 수신자를 언제 세나요?** 예약 누른 순간 명단이 고정되는지, 발송 시각에 그룹을 다시 세는지. 그룹은 실시간으로 바뀌는데(광고 동의 + 결제자 제외), 예약 뒤에 들어온 리드가 빠지거나 그사이 결제한 사람에게 광고 메일이 가는지 알 수가 없음. 예약 화면에 "발송 시점 기준"인지 표시 요청.
   - 화면: https://docurise.io/dashboard/automations (그룹: 유비챌 11기 · 오늘 결제 이탈 (1일))
5. **결제 이탈 트리거 자동화**: 사람별 "이탈 +N시간" 자동 메일이 Rising엔 없음. Iconic 조건 분기로 되는지, Rising 애드온으로는 안 되는지.
   - 화면: https://docurise.io/dashboard/automations
6. **폴더로 들어온 리드는 문서별 자동화가 안 켜짐**: 폴더 이메일 게이트로 들어와 안의 문서 5개를 열어도 "문서 조회 시" 자동화 5개가 전부 등록 0명. 폴더 전용 트리거나 폴더 열람도 문서 조회로 쳐주는 옵션 필요. (그룹 조건 document_view 는 폴더 방문을 포함하는데 자동화 트리거는 아님)
   - 화면: https://docurise.io/dashboard/folders/9e9ff2d1-52bf-45fd-b197-a3b285dcb8e0 / https://docurise.io/dashboard/automations/b269111b-32b6-4c16-8052-6b1f8a9df0a8
7. **받는 사람 이름 기본값에 "이메일 앞부분" 옵션**: 이메일만 받는 리드는 이름이 비어서 "{이름}님,"이 "님,"으로 나감. 기본값을 고정 단어만 넣을 수 있는데, 이메일 @ 앞부분을 쓰는 옵션이 있으면 좋겠음.
   - 화면: https://docurise.io/dashboard/automations/8ca5bd1d-e9c8-4cc2-86a8-a5bd73889c82
8. **API/MCP로 자동화 켜기·캠페인 삭제·예약 시각 변경이 안 됨**: 초안까지만 되고 나머지는 전부 대시보드에서 손으로. 자동화가 연결된 결제 폼은 MCP로 질문·버튼·배너를 못 고침 (대시보드에서는 됨).
9. **알림톡 버튼 문구**: 플랫폼 템플릿 버튼이 전부 "확인하기"라 단톡방 입장 유도가 약함. "입장하기" / "참여하기" 버튼 템플릿 추가 요청.
   - 화면: https://docurise.io/dashboard/automations/41c67081-7d14-4b5a-86b6-2f98e3584843

## 3. 리드·연락처·동의
10. **리드 상세에 운영자 메모란**: 지금은 태그만 있음. "환불 예정", "1일1비 시작일 11/20", "닉네임 Sue" 같은 걸 적을 칸.
   - 화면: https://docurise.io/dashboard/contacts
11. **폴더 이메일 게이트의 마케팅 동의 문구를 바꿀 수 없음**: 개별 문서는 직접 쓸 수 있는데 폴더는 켜기/끄기만 있음. 기본 문구가 딱딱해서 폴더 리드 절반만 체크. 문서와 같은 문구 칸 요청.
   - 화면: https://docurise.io/dashboard/folders/9e9ff2d1-52bf-45fd-b197-a3b285dcb8e0?tab=settings / https://docurise.io/youbuddy/f/5-4j9rd71y
12. **동의 안 한 리드가 연락처에 "구독 취소"로 표시**: 메일 한 통 못 받은 사람인데 직접 수신거부한 걸로 오해함. "미동의"처럼 구분 표시.
   - 화면: https://docurise.io/dashboard/contacts
13. **동의 문구 앞 "(선택)" 자동 추가가 편집 화면에서 안 보임**: 문구에 "(선택)"을 직접 쓰면 실제 화면에 "(선택) (선택) …"으로 두 번 나옴. 편집 칸 옆에 자동으로 붙는다고 표시.
   - 화면: https://docurise.io/dashboard/documents/a69729a5-4f28-4bd6-a171-08cd7eb1471c / https://docurise.io/v/youbuddy-salary-d5

## 4. 분석·유입 추적
14. **대시보드 문서 분석 탭이 0으로 나옴**: 상세페이지·자료 5종 분석 탭이 총 조회수 0, 링크 클릭 0인데, 같은 기간 요약 통계로는 조회·리드가 있음. 어느 쪽이 맞는지 확인 필요.
   - 화면: https://docurise.io/dashboard/documents/6b463de2-86dd-422f-9643-687a68c4fb77?tab=analytics
15. **폴더에는 채널(src) 설정이 없음**: 문서는 "다른 채널 추가하기"로 게시물별 링크를 만들 수 있는데 폴더는 공유 탭이 없어서, 어느 게시물에서 들어왔는지 알 수 없음.
   - 화면: https://docurise.io/dashboard/folders/9e9ff2d1-52bf-45fd-b197-a3b285dcb8e0
16. **커스텀 채널이 MCP 통계에 안 나옴**: 대시보드에서 ig_dm-132 같은 채널을 추가해도 MCP 채널 통계는 기본 채널과 "기타"만 돌려줌.
   - 화면: https://docurise.io/dashboard/documents/6b463de2-86dd-422f-9643-687a68c4fb77?tab=access

## 5. 문서·폴더·페이지 기능
17. **커스텀 도메인** (꼭): docurise.io/v/... 대신 내 도메인(예: ubchal.youbuddy.co.kr)으로 상세페이지를 열 수 있는지. 요금표에 항목 없음.
   - 화면: https://docurise.io/v/youbuddy-challenge-11
18. **"Powered by DocuRise" 배지 제거**가 Rising에서도 유료 옵션으로 가능한지 (Iconic부터만 명시).
   - 화면: https://docurise.io/youbuddy
19. **만료 없이 거는 리다이렉트**: 예전 슬러그 문서로 리드가 새는 걸 막으려면 "이 문서 대신 저 문서로 보내기"를 바로 걸 수 있으면 좋겠음. 지금은 만료일을 과거로 넣어야만 걸림.
   - 화면: https://docurise.io/dashboard/documents (만료된 v01 문서들)
20. **포스트 HTML 기본 인터랙션 허용 목록**: script가 지워지는 건 이해하지만 FAQ 펼치기·후기 자동 흐름 같은 기본 인터랙션용 허용 목록 요청. (지금은 details/summary + CSS로 우회)
   - 화면: https://docurise.io/dashboard/documents/6b463de2-86dd-422f-9643-687a68c4fb77
21. **노션 문서 하위 페이지 트리 없음**: 하위 페이지를 펼쳐 볼 수 없고 하나씩 들어갔다 나와야 함.
   - 화면: https://docurise.io/dashboard/documents/aac73b8f-f923-4667-b855-3dd4f63815a7 (노션 주간일지 템플릿)
22. **대시보드 문서 탭에서 폴더를 펼쳐 보기 (토글)**: 운영자 화면 "문서" 목록에서 폴더를 누르면 폴더 페이지로 넘어가 버려서, 안에 뭐가 들었는지 보려면 들어갔다 나와야 함. 문서 목록 안에서 폴더 옆 화살표를 누르면 그 자리에서 안의 문서들이 펼쳐지는 토글(트리) 보기 요청. 폴더가 늘어날수록 어떤 문서가 어느 폴더에 있는지 한눈에 안 보임.
   - 화면: https://docurise.io/dashboard/documents
23. **문서·폴더 미리보기를 모바일 화면으로도**: 지금은 PC 화면으로만 확인되고, 모바일은 폰으로 열어봐야 깨진 걸 알게 됨.
   - 화면: https://docurise.io/dashboard/documents/34c6b007-e324-4de8-b176-5eda1549a7aa

## 6. 대시보드 UI 버그
24. **모바일 리드 화면 깨짐** (2026-11-08 캡처, 아이폰 사파리): "수집된 리드 2개 중 2개 표시"가 세로로 한 글자씩 꺾여 내려감. 옆 "Google Sheets 연결 / CSV 내보내기" 버튼이 자리를 다 차지해서 생기는 문제. 좁은 화면에서는 버튼을 아래 줄로. 오른쪽 아래 채팅 버튼(주황 원)이 페이지 넘김 버튼을 가림.
   - 화면: https://docurise.io/dashboard/documents/479f7321-37cb-4ab0-838c-49ea3ea4bfaa (온보딩 설문 리드, 모바일)
25. **자동화 편집 화면** (2026-11-06 캡처): "대상 문서" 드롭다운에 긴 제목을 고르면 글자가 세로로 흘러내려 아래 블록을 덮음. 한 줄 말줄임으로.
   - 화면: https://docurise.io/dashboard/automations/b269111b-32b6-4c16-8052-6b1f8a9df0a8
26. **카카오 테스트 발송 모달** (2026-11-06 캡처): 변수 값이 오른쪽 정렬이라 긴 값이 "..."로 잘리고, 모달 뒤 알림톡 폰 미리보기가 비쳐 보여 헷갈림. 값은 왼쪽 정렬 + 줄바꿈, 모달 뒤 배경은 가리기.
   - 화면: https://docurise.io/dashboard/automations/41c67081-7d14-4b5a-86b6-2f98e3584843
27. **프로필 링크 블록**: 묶음(2열·3열) 안 링크는 이모지 칸이 없어 그림을 꼭 올려야 함. 링크 카드 제목 24자 제한이 줄바꿈 포함이라 두 줄 제목이 금방 막힘.
   - 화면: https://docurise.io/dashboard/settings/profile / https://docurise.io/youbuddy
28. **대시보드 검색·목록**: 괄호·파이프 들어간 제목을 검색이 못 찾음. MCP로 만든 문서가 목록에 늦게 뜨다가 비활성/활성 토글 뒤에 나타남.
   - 화면: https://docurise.io/dashboard/documents/18bb31ae-cf98-4121-b358-c02cc5c36a06 (유버디 영어단어장 (노션 템플릿) | ...)

## 확인된 사실 (참고, 보낼 때는 빼기)
- 수수료: Rising 3.9% + PG / Iconic 2.9%. 환불 시 플랫폼 수수료는 환불 비율만큼 돌려줌, PG가 환급하지 않는 비용은 크리에이터 부담 (약관 12.5).
- 환불: 결제일 7일 이내는 대시보드에서 직접(부분환불 가능), 그 뒤는 고객센터 경유. 청약철회 3영업일 내 환급.
- 유입 채널: ?src=채널 또는 utm_source 로 "채널별 유입"에 잡힘. utm_medium·utm_content 는 안 읽음.
