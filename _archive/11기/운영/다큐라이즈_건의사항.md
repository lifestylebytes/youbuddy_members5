# 다큐라이즈(DocuRise) 건의·문의 모음

11기 퍼널을 다큐라이즈로 옮기면서 막힌 것들. 고객센터에 한 번에 보낼 용도. (2026-11-06 시작)

## 꼭 물어볼 것
1. **커스텀 도메인**: docurise.io/v/... 대신 내 도메인(예: ubchal.youbuddy.co.kr)로 상세페이지를 열 수 있는지. 요금표에 항목 없음.
2. **수신자 0명이면 예약 발송을 못 거는 문제**: 그룹(예: "최근 1일 결제 이탈")을 대상으로 예약을 걸어두고, 발송 시각에 그룹을 다시 세서 0명이면 건너뛰고 N명이면 보내는 식으로 "켜둘 수" 있게 해달라. 지금은 누르는 순간 0명이면 버튼이 비활성화라 결제 이탈 메일을 매일 손으로 보내야 함.

## 같이 물어볼 것
3. 결제 이탈(checkout_abandoned) 트리거 자동화: 사람별 "이탈 +N시간" 자동 메일이 Rising 플랜엔 없음. Iconic 조건 분기 자동화로 되는지, Rising 애드온으로는 안 되는지.
4. "Powered by DocuRise" 배지 제거가 Rising에서도 유료 옵션으로 가능한지 (Iconic $99부터만 명시).
5. 결제 폼 질문을 만든 뒤 수정 못 하는 것 (오타 하나 고치려면 폼을 새로 만들고 상세페이지 연결을 다시 해야 함).
6. 폼의 "제출 후 화면"으로 연결한 포스트는 제출자만 열 수 있어서, 결제한 사람이 나중에 다시 못 들어감. 결제 완료자는 재방문 허용되게.
7. 해외 발급 카드 결제 가능 여부 (KRW·Payple 경로).
8. 포스트 HTML에서 script가 전부 지워지는 건 이해하지만, FAQ 펼치기·후기 자동 흐름 같은 기본 인터랙션용 허용 목록이 있으면 좋겠음. (지금은 details/summary + CSS 애니메이션으로 우회)
9. API/MCP로 자동화 켜기·캠페인 삭제·예약 시각 변경이 안 됨. 초안까지만 되고 나머지는 전부 대시보드에서 손으로.
10. **카카오 테스트 발송 모달 UI** (2026-11-06 캡처): 미리보기 표의 변수 값이 오른쪽 정렬이라 긴 값("참여방식")이 "..."로 잘리고, 모달 뒤의 알림톡 폰 미리보기가 모달과 겹쳐 비쳐 보여서 뭐가 실제 문구인지 헷갈림. 값은 왼쪽 정렬 + 줄바꿈으로 전부 보이게, 모달 뒤 배경은 가려주면 좋겠음.
11. **리드(연락처) 상세에 운영자 메모란**: 지금은 태그만 있고 자유 메모가 없음. "환불 예정", "1일1비 시작일 11/20", "닉네임 Sue" 같은 걸 적을 칸이 필요.
12. **알림톡 버튼 문구**: 플랫폼 템플릿 버튼이 전부 "확인하기"라 단톡방 입장 유도가 약함. "입장하기" / "참여하기" 버튼 템플릿 추가 요청.

## 확인된 사실 (참고)
- 수수료: Rising 3.9% + PG / Iconic 2.9%. 환불 시 플랫폼 수수료는 환불 비율만큼 돌려줌, PG가 환급하지 않는 비용은 크리에이터 부담 (약관 12.5).
- 환불: 결제일 7일 이내는 대시보드에서 직접(부분환불 가능), 그 뒤는 고객센터 경유. 청약철회 3영업일 내 환급.
- 유입 채널: ?src=채널 또는 utm_source 로 "채널별 유입"에 잡힘.
13. **노션 문서 하위 페이지 트리 없음**: 다큐라이즈로 가져온 노션 문서는 하위 페이지를 펼쳐 볼 수 없고 하나씩 들어갔다 나와야 함. 사이드바나 펼치기 트리가 있으면 좋겠음.
14. **대시보드 검색이 괄호·파이프 들어간 제목을 못 찾음 / MCP로 만든 문서가 목록에 늦게 뜸** (2026-11-06): "유버디 영어단어장 (노션 템플릿)" 검색 결과 없음. API로는 live 인데 목록에선 안 보이다가 비활성/활성 토글 뒤에 나타남.
15. **자동화 편집 화면 UI** (2026-11-06 캡처): "대상 문서" 드롭다운에 긴 제목을 고르면 제목 글자가 드롭다운 밖으로 세로 한 글자씩 흘러내려 3번 블록까지 덮음. 선택된 제목은 한 줄 말줄임으로.
16. **폴더로 들어온 리드는 문서별 자동화가 안 켜짐** (2026-11-07): 폴더 이메일 게이트로 들어와 안의 문서 5개를 열어도 "문서 조회 시" 자동화 5개가 전부 등록 0명. 폴더 전용 트리거("폴더 이메일 입력 시")나 폴더 열람도 문서 조회로 쳐주는 옵션이 필요. (그룹 조건 document_view 는 폴더 방문을 포함하는데 자동화 트리거는 아님. 둘이 다르게 동작해서 헷갈림)
17. **판매 웹훅 / 주문 내보내기 없음** (2026-11-07): 결제 완료 시 외부로 웹훅을 쏘거나 주문 목록을 CSV로 내보낼 방법이 없음. Google Sheets 연동은 Iconic 플랜 전용이고 "리드" 동기화라 구매자 시트(이름·이메일·상품·금액·결제일)를 따로 쌓기 어려움. 최소한 주문 CSV 다운로드 + 결제 완료 웹훅 요청.
18. **문서 미리보기를 모바일로도** (2026-11-07): 문서·폴더 미리보기를 모바일 화면 기준으로도 볼 수 있게 해주세요. 지금은 PC 화면으로만 확인하고, 모바일은 폰으로 직접 열어봐야 깨진 걸 알게 됨.
19. **v01 문서 정리**: 예전 슬러그를 그대로 둔 문서로 리드가 새는 걸 막으려면 "이 문서 대신 저 문서로 보내기(리다이렉트)"를 만료 없이 바로 걸 수 있으면 좋겠음. 지금은 만료일을 과거로 넣어야만 리다이렉트가 걸림.
20. **폴더 이메일 게이트의 마케팅 동의 문구를 바꿀 수 없음** (2026-11-07): 개별 문서는 동의 체크박스 문구를 직접 쓸 수 있는데, 폴더 설정에는 "마케팅 동의" 켜기/끄기만 있고 문구 칸이 없음. 기본 문구가 딱딱해서 폴더 리드 12명 중 6명만 체크. 문서와 같은 문구 입력 칸 요청.
21. **동의 체크 안 한 리드가 연락처 목록에 "구독 취소"로 표시됨** (2026-11-07): 메일 한 통 못 받은 사람인데 "구독 취소"라고 떠서, 직접 수신거부를 누른 걸로 오해함. "미동의"처럼 구분되는 표시로 바꿔주면 좋겠음.
22. **모바일 리드 화면 UI 깨짐** (2026-11-08 캡처, 아이폰 사파리): 폼 리드 화면에서 "수집된 리드 2개 중 2개 표시"가 세로로 한 글자씩 꺾여 내려감. 옆의 "Google Sheets 연결 / CSV 내보내기" 버튼이 자리를 다 차지해서 생기는 문제. 좁은 화면에서는 버튼을 아래 줄로 내리고 문구는 한 줄로. 오른쪽 아래 채팅 버튼(주황 원)이 페이지 넘김 버튼을 가려서 다음 페이지를 못 누름.
23. **대시보드 문서 분석 탭이 0으로 나옴** (2026-11-08): 상세페이지·자료 5종 분석 탭이 총 조회수 0, 링크 클릭 0으로 보이는데, 같은 기간 MCP/요약 통계로는 조회·리드가 있음. 둘 중 어느 쪽이 맞는지 확인 필요.
24. **폴더에는 채널(src) 설정이 없음** (2026-11-08): 문서는 "다른 채널 추가하기"로 게시물별 링크를 만들 수 있는데 폴더는 공유 탭 자체가 없어서, 자료 5종 폴더로 어느 게시물에서 들어왔는지 알 수 없음. 폴더에도 채널 링크 요청.
25. **커스텀 채널이 MCP 통계에 안 나옴** (2026-11-08): 대시보드에서 ig_dm-132 같은 채널을 추가해도 MCP 채널 통계는 기본 채널(ig_dm·ig_bio·kakao 등)과 "기타"만 돌려줌. 직접 만든 채널도 이름 그대로 내려주면 좋겠음.
26. **이메일 받는 사람 이름 기본값에 "이메일 앞부분" 옵션** (2026-11-07): 이메일만 받는 폴더·자료 리드는 이름이 비어서 "{이름}님,"이 "님,"으로 나감. 기본값을 고정 단어만 넣을 수 있는데, 이메일 @ 앞부분을 쓰는 옵션이 있으면 좋겠음.
27. **프로필 링크 블록 UI** (2026-11-07): 묶음(2열·3열) 안 링크는 이모지 아이콘 칸이 없어서 그림을 꼭 업로드해야 함. 일반 링크 카드처럼 이모지 칸 요청. 링크 카드 제목 24자 제한도 줄바꿈 포함 기준이라 두 줄 제목이 금방 막힘.
28. **마케팅 동의 문구 앞 "(선택)" 자동 추가가 편집 화면에서 안 보임** (2026-11-07): 문구에 "(선택)"을 직접 쓰면 실제 화면에 "(선택) (선택) …"으로 두 번 나옴. 편집 칸 옆에 자동으로 붙는다고 표시해주면 좋겠음.
