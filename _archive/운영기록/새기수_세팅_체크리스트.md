## 1. 기계적인 것 → 스크립트 한 방

```
python3 _archive/운영기록/scripts/new_cohort.py --from 9th --to 10th --cohort 10기 \
  --start 2026-10-19 --end 2026-11-13 --theme "#주색,#진한색,#연한색,#고스트색" --kakao https://open.kakao.com/o/XXXX
```

스크립트가 처리하는 것: 폴더 복사·리포트 제거 · sw.js 캐시 prefix · manifest(start_url/scope/id/name/색) ·
localStorage 키(yb{N}_) · cohort/start/end/APP_BUILD/화면 "N기" 문구 · 운영진만 남긴 명단 ·
MEMBER_REPORTS/PREMIUM_MEETING_STATS 비움 · 미팅 녹화본/리캡 비움 · 테마색 치환 · 카톡방 링크 · 검증 3종.

9기 때 빠뜨렸다가 피드백으로 잡은 것들 (스크립트에 이미 반영됨, 다시 빠지면 안 됨):
- manifest start_url 이 이전 기수로 남아서 갤럭시 "바로가기 만들기"가 8기를 설치함
- 녹음 제출 버튼이 이전 기수 카톡방으로 감 (KAKAO_ROOMS)
- localStorage 키가 같아 이전 기수 상태와 섞임 (yb8_ → yb9_)
- 보드 색·설명서 스와치·투어 문구에 이전 테마색(파랑) 잔존 → 테마 바꾸면 `grep` 으로 hex 잔여 0 확인
