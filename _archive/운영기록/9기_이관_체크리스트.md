## 2. 새 기수마다 갈아끼우는 것 (COHORT-SLOT)

`grep -n "COHORT-SLOT" 9th/index.html` 하면 전부 나온다. 8기 기준 14곳.

- 오픈채팅방 링크 2개 (베이직/프리미엄)
- `MEMBER_DIRECTORY` 명단 + `kakao` 표시명 + `tz` 시차
- `MEMBER_REPORTS` 비우기 (발표 리포트, 사람당 한글+영문 두 키!)
- 미팅 4회 날짜 + Meet 링크 (공지에 쓴 링크와 일치 확인!)
- 회의 시뮬 12문항, 주차 오프닝 멘트, 베스트 문장, 데일리 펄스
- `WEEK1_DECK` 슬라이드 문구 (로드맵 주차 테마 확인. 8기: 2주차 위기 대응 / 3주차 스몰톡)
- ⚠️ 8기 미완: Week 2 롤플레잉이 아직 "논쟁의 기술" 콘텐츠. 위기 대응으로 교체 필요

## 4. 구글 시트 (유비챌_기수_운영로그)

`_archive/운영기록/유비챌_시트_자동화.gs` 를 Apps Script 에 붙여넣고:

1. 상수 수정: `COHORT='9기'`, `START_DATE`, `MORNING`/`SPOON` 원고
2. `splitMorningSheet` → `fillOpsMessages` → `linkChecklistMessages` → `refreshChecklist` 순서로 실행
3. `setupTrigger` (매일 07:00 인증률 자동 기록)

⚠️ **절대 규칙: 체크리스트 D(시각)·E(담당)·G(지침)·H(링크) 열은 6행 배열 수식이다.**
중간 셀에 값을 쓰면 열 전체가 #REF! 로 깨진다. 규칙 변경은 6행 수식 수정으로만.
(8기 때 두 번 깨뜨림. 복구는 `fixChecklistTimes` / `fixChecklistOwners`)

시각 체계: 06:00 모닝공지 → 07:00 인증률(자동) → **08:00 유버디 아침 안내** → **19:00 한 스푼 더** → 20:30 녹음 마감 → 21:00 미인증 리마인드 → 21:30 1:1 케어

## 5. 운영 루틴 (사람이 하는 것)

- **미팅 전날**: 대본(노션)과 발표 페이지(WEEK N_DECK) 싱크 확인 · Meet 링크 확인 · 녹화 테스트
  (8기 W1 사고: 대본과 슬라이드가 안 맞아서 미팅 직전에 전면 재작성)
- **미팅 직후**: 받아적기 저장 (저장 성공 토스트 "N명 저장 완료" 확인!) · 녹화 중지 먼저 누르고 나가기
- **미팅 다음날 08:00**: 통합 공지 (녹화본+과제 안내+Q&A 링크+발표 예약)
- **미팅 Q&A**: 나온 질문은 설명서 `#help` 미팅 Q&A 챕터에 `foldCard` 로 추가 (프리미엄 전용 섹션)
- 미팅 기록은 `_archive/{기수}/운영/{기수}_WeekN_미팅기록.md` 로 남긴다 (8기 Week1 참고)

## 6. 8기에서 잡은 버그 (9기에서 재발하면 이 문서 탓)

1. RPC 파라미터 이름 불일치 → 앱은 토스트만 뜨고 조용히 넘어감. 새 RPC 는 curl 로 먼저 검증
2. 사전형↔실문장 불일치로 퀴즈 정답 노출
3. 15초 폴링이 읽기 페이지 재렌더 → 아코디언 닫힘
4. 운영자 티어 토글이 프리미엄 잠금을 못 잠금
5. 배열 수식 셀 직접 입력 → 열 전체 #REF!
6. 미팅 대본과 발표 페이지 불일치
7. placeholder 로만 이름 표시 → 타이핑하면 누구 칸인지 사라짐
