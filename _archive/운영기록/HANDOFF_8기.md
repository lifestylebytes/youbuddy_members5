## 3. 회고노트 "재분석 필요" 2건 · 결론 (2026-08-08)

### ① "3주차 이탈이 많지 않았다" → **부분적으로만 맞다**

- 성공 기준 "3주차 80% 유지"는 **53.7%로 미달**
- 매주 8~11%p씩 **일정하게** 하락. 어느 주에도 절벽 구간 없음
- → "예고가 급락을 막았다"는 해석은 가능하나, **이탈 자체는 못 막았다**

### ② "4번 block으로 연명" → **거의 틀렸다**

미인증 명단으로 각자 최장 연속 미인증을 계산한 결과:

- **연명형** (자주 빠지지만 3연속은 안 감): **1명** (zoey)
- **사실상 이탈** (5일 이상 연속 미인증): **12명**. 11일 연속이 8명

한 번 끊기면 대부분 안 돌아왔다. block이 복귀를 만든 증거는 없다.
**다만 13~17일 구간이 9명(25.7%)으로 이례적으로 두껍다.** 이게 예고·block의 진짜 효과일 수 있으므로
**8기에서 같은 지표로 측정해 6기·7기와 비교할 것.**

### ③ "후기에 강제성 언급이 많았다" → **검증 불가**

**후기 수집 0건**이라 표본이 없다. 카톡 멤버 발화 173건 중 강제성 관련 22건은
거의 전부 **"내 인증 누락됐나요?" 문의**였다. 시스템에 붙어 있다는 신호로는 읽히나 후기는 아니다.

> **8기 액션: 수료식 전에 후기를 반드시 받는다.** 단톡방 요청만으로는 0건이었으므로
> 보상(1일1비 7일권 등)을 걸고 개별로 찔러야 한다.

## 4. 절대 규칙 (위반 이력이 있는 것들)

### 운영

1. **기수 중간에 수료 기준을 조이지 않는다.** (7기 Day 17 지각 0.5점 사건, 되돌림)
2. **마감을 만들지 않는다.** 학습·파이널 영구 개방
3. **실제로 주지 않을 혜택을 화면에 쓰지 않는다.** 수료 특가·얼리버드 쿠폰·카운트다운
4. **고객센터 채널 안내가 항상 맨 위.** 📌 목록에 섞으면 그냥 넘어간다
5. **베이직 공지에 프리미엄 전용 항목(사전 진단지 등)을 쓰지 않는다**
6. **공지는 "없는 것"부터 말하지 않는다.** "따로 모이는 시간 없어요"(X) → "링크 하나로 끝나요"(O)
7. **샘플·홍보물에 실제 멤버 사례를 쓰지 않는다.** 이름 지워도 같은 기수는 알아본다

### 글쓰기

- **em dash(—) 절대 금지.** 산출물마다 `grep "—"` 0건 확인
- **멤버 대면 텍스트에 "가비" 금지.** "버디"/"유버디"만. `grep "가비" 8th/index.html` 0건
- **"미인증자" 대신 "미인증".** '자'가 붙으면 지목하는 느낌
- **멤버 이름 들어간 산출물(수료 카드 PNG, 코칭 시트)은 커밋 금지.** `.gitignore` 확인

### 앱 코드

- **연속 푸시 금지.** GitHub Pages는 새 푸시가 진행 중인 빌드를 취소한다.
  **반영 안 될 때 코드보다 빌드 상태를 먼저 의심.** (2번 당했음)
- **커밋 전 검증 3종**: `<script>` 블록 파싱 + `grep "—"` 0건 + `grep "가비"` 0건
  (단, 이 문서와 `CLAUDE.md` 는 **규칙을 서술하느라** 두 문자를 포함한다. 검사 대상에서 제외)
- **함수 반환 필드명을 바꾸면 소비처 전수 grep.** JS는 오타난 속성에서 `undefined`를 조용히 흘린다
  (`.score` → `.days` 변경으로 완주 메달이 아무에게도 안 보였던 사고)
- **지각 판정은 `dayStatus(d) === 'done-late'` 로만.** `state.verified_late`는 레거시
- **완주 판정은 본인/남의 경로가 다르다.** 본인 `computeVerifyScore().days`, 남 `m.progress`
- **정렬 로직은 `memberSortCompare` 말고 `Checkboard`의 `orderedMembers`도 확인.** 인증 보드는 후자를 쓴다
- **서비스워커는 자기 prefix 캐시만 지운다.** `youbuddy-8th-`
- **팝업 만들면 트리거를 실제로 호출하는지 확인.** 컴포넌트만 있고 부르는 데 없던 사고 있음
