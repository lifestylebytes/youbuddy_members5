## 대시보드에 물릴 때

`Buddy True North Dashboard` 는 노션과 구글 캘린더를 읽는다. 로컬 파일은 못 읽는다.
그래서 이 폴더를 대시보드에 반영하려면 둘 중 하나가 필요하다.

1. `기수_운영_타임라인.md` 의 체크리스트를 **노션 `유버디 운영 OS` 아래 페이지로 올린다.**
   그러면 대시보드의 "유버디 운영 OS 우선순위" 블록이 그대로 읽어간다.
2. 날짜별 항목을 **구글 캘린더 일정으로** 만든다.
   D-2 고객센터 안내, D-1 코드 발송처럼 놓치면 안 되는 것만이라도.

**권장: 8기부터 1번.** 타임라인이 노션에 있으면 대시보드가 "오늘 뭐 해야 하는지"를
직접 띄워주므로, 기수마다 이 문서를 열어보는 수고가 사라진다.
